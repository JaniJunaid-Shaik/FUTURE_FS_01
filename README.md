# FUTURE_FS_01
# Personal Professional Portfolio Website

## Future Interns – Full Stack Web Development Task 1

This project is a personal professional portfolio website developed as part of the **Full Stack Web Development Internship Program at Future Interns**.

The purpose of this portfolio is to showcase my skills, projects, background, resume, and provide a way for recruiters, clients, and other professionals to connect with me.

## 🚀 Features

- Professional homepage
- About Me section
- Skills and technology section
- Projects showcase
- Resume section
- Contact section
- Responsive design for desktop and mobile devices
- Smooth navigation between sections
- Contact form with basic validation
- SEO-friendly HTML structure

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Git
- GitHub
- Visual Studio Code
